    \section{Scope}
        This document specifies the software requirements for the Spacecraft Cube 
        Attitude Determination System (SCADS) v1.0. SCADS v1.0 is a portfolio 
        demonstration project implementing a fault-tolerant finite state machine 
        for attitude determination and control on a simulated 1U CubeSat platform, 
        running on bare-metal hardware under FreeRTOS.
        The v1.0 scope covers:
        \begin{itemize}
            \item Five-state operational finite state machine with formally 
                    defined transitions
            \item Fault detection for sensor dropout, out-of-range readings,
                    task overruns, watchdog events, and estimator divergence
            \item Attitude estimation using a simplified estimator with 
                    characterized uncertainty growth
            \item Attitude control for Detumble and Safe modes; Nominal-mode 
                    control is implemented as a stub that maintains zero
                    commanded torque for attitude hold
            \item Ground command processing for a minimal command set
            \item Local event and state logging to non-volatile storage
        \end{itemize}
        The following capabilities are deferred to v2.0 and beyond:
        \begin{itemize}
            \item Full attitude tracking control for arbitrary commanded 
                    attitudes
            \item Translational maneuver execution (thruster control)
            \item Ground telemetry packet generation and transmission
            \item Mission-time correlation and absolute time synchronization
            \item Multi-sensor fusion estimation 
                    (e.g., Extended Kalman Filter)
            \item Sensor redundancy and voting
        \end{itemize}
        Requirements related to deferred capabilities are not included in this document.

        \subsection{State Transition Requirements}

            The following table provides some common definitions used within
            the State Transition Requirements.

            \begin{table}[H]
            \caption{Common Definitions}
            \vspace{4pt}
            \centering
            \renewcommand{\arraystretch}{1.4}
            \begin{tabular}{|l|p{14cm}|}
                \hline
                \textbf{Phrase} & \textbf{Definition} \\ \hline
                Sensor Fault & Refers to a sensor going offline for 
                    SD\_CONSECUTIVE\_NUM\_SAMPLES consecutive samples or 
                    SD\_TRIGGER\_AGGREGATE\_SAMPLES samples per the last 
                    SD\_AGGREGATE\_SAMPLES. \\ \hline
                Sensor Recover & Refers to a sensor coming back online for 
                    SR\_CONSECUTIVE\_NUM\_SAMPLES consecutive samples or 
                    SR\_TRIGGER\_AGGREGATE\_SAMPLES samples per the last 
                    SR\_AGGREGATE\_SAMPLES. \\ \hline
                High Rotation & When the measured rate of rotation exceeds 
                    ROTATION\_RATE\_HIGH $\mathrm{rad/s}^2$ over ROTATION\_SAMPLES\_HIGH 
                    consecutive samples. \\ \hline
                Low Rotation & When the measured rate of rotation is less than
                    or equal to ROTATION\_RATE\_LOW $\mathrm{rad/s}$ over 
                    ROTATION\_SAMPLES\_LOW consecutive samples. \\ \hline
                High Uncertainty & When the measured attitude uncertainty exceeds 
                    UNCERATINTY\_HIGH units per UNCERTAINTY\_SAMPLES\_HIGH 
                    consecutive samples. \\ \hline
                Low Uncertainty & When the measured attitude uncertainty is
                    less than UNCERATINTY\_LOW units per UNCERTAINTY\_SAMPLES\_LOW 
                    consecutive samples. \\ \hline
                \end{tabular}
            \end{table}
